# 📿 أذكار الصباح والمساء — حصن المسلم بالمصادر

موقع عربي أنيق (RTL) لأذكار الصباح والمساء الصحيحة بمصادرها + مسبحة إلكترونية متعددة الأذكار.

## ✨ المميزات
- 28 ذكراً صحيحاً بمصادرها (البخاري، مسلم، أبو داود، الترمذي...) ودرجة الحديث
- تبويبات: ☀️ الصباح / 🌙 المساء / 📿 المسبحة / ⭐ المفضلة
- عداد لكل ذكر + شريط إنجاز + حفظ تلقائي (localStorage)
- 👴 شريط كبار السن: تكبير/تصغير الخط (A+ / A-)
- 🌙 وضع ليلي (دارك) + ثيم بنفسجي
- خطوط عربية: Rakkas (ديواني) + Aref Ruqaa + Amiri + Tajawal
- مسبحة متعددة الأذكار مع أهداف 33/100/500/1000 وهدف مخصص
- بحث فوري + نسخ + يعمل بدون إنترنت (ما عدا الخطوط)

## 🚀 التشغيل
افتح `index.html` مباشرة بالمتصفح — لا يحتاج سيرفر.

## 🌐 النشر على GitHub Pages
بعد رفع المشروع فعّل Pages من:
`Settings → Pages → Deploy from branch → main → / (root)`

## 📚 المصادر
صحيح البخاري، صحيح مسلم، سنن أبي داود، سنن الترمذي، ابن ماجه، مسند أحمد، النسائي — بتحقيق الألباني وابن باز. اعتمدنا حصن المسلم.
